# 의료 QA에서 LLM 할루시네이션 감소: R-Tuning과 DPO 비교

한국어 의료 질문에서 LLM의 오답과 근거 없는 응답을 줄이고, 답하기 어려운 질문에서 적절하게 거절하도록 학습하는 프로젝트입니다.

같은 데이터와 EXAONE 원본 모델에서 출발해 **R-Tuning**과 **DPO**를 각각 적용하고, 공통 평가 조건으로 결과를 비교합니다. 오답 전체를 할루시네이션으로 간주하지 않습니다.

## 저장소 구조

```text
.
├─ README.md
├─ .gitignore
├─ common/                 # 두 방법에서 함께 사용하는 자료
│  ├─ scripts/             # 전처리·생성·채점·평가 코드
│  ├─ configs/             # 모델·환경·프롬프트·생성 설정
│  ├─ splits/              # 질문 원문을 제외한 데이터 분할 ID
│  └─ reports/             # 집계 성적·검토 결과
├─ r_tuning/               # 진경: R-Tuning 학습 코드·설정
└─ dpo/                    # 채은: DPO 학습 코드·설정
```

위 구조는 저장소 구성 기준입니다. 실행 파일을 옮길 때는 기존 스크립트의 입력·출력 경로도 함께 수정해야 합니다.

## 데이터

- **사용 데이터:** AI Hub [필수의료 의학지식 데이터](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&dataSetSn=71875)
- **사용 유형:** 단답형(`q_type=2`), 서술형(`q_type=3`)
- **제외 유형:** 객관식(`q_type=1`)

기존 「초거대 AI 헬스케어 질의응답 데이터」는 질문과 답변이 분리되어 있어, 범주를 이용한 후보 매칭만으로 정확한 연결을 확정하기 어려웠습니다. 질문과 답변이 같은 레코드에 연결된 현재 데이터로 변경했습니다. 기존 데이터에서 얻은 파일럿 성적은 현재 데이터의 성적과 직접 비교하지 않습니다.

| 분할  | 질문 수 | 단답형 | 서술형 | 용도                      |
| ----- | ------: | -----: | -----: | ------------------------- |
| train |   2,598 |  1,310 |  1,288 | 각 방법의 학습 재료 구성  |
| valid |     288 |    145 |    143 | 학습 설정·체크포인트 선택 |
| test  |     366 |    179 |    187 | 최종 비교                 |

원래 Training 데이터 2,886개를 train·valid로 분할했고, 원래 Validation 데이터 366개를 test로 사용했습니다. 분할 seed는 42이며 질환 영역·질문 유형을 고려했습니다. 분할 간 동일 질문 중복은 없었고, 수행한 유사 질문 검사에서는 설정한 기준을 넘는 후보가 없었습니다. 이는 의미상 중복이 전혀 없다는 보장은 아닙니다.

## 공통 모델과 환경

| 항목                     | 설정                                                |
| ------------------------ | --------------------------------------------------- |
| 모델                     | `LGAI-EXAONE/EXAONE-3.5-2.4B-Instruct`              |
| 모델·토크나이저 revision | `e949c91dec92095908d34e6b560af77dd0c993f8`          |
| 학습 출발점              | Instruct 원본, 공통 SFT 생략                        |
| 입력 형식                | `apply_chat_template`, `add_generation_prompt=True` |
| 시스템 프롬프트          | 없음                                                |
| 실행 GPU                 | 학교 서버 NVIDIA RTX 4000 Ada Generation            |
| 추론 dtype               | `bfloat16`                                          |
| Python                   | 3.10.22                                             |
| torch                    | 2.5.1                                               |
| transformers             | 4.46.3                                              |
| accelerate               | 1.1.1                                               |
| peft                     | 0.13.2                                              |
| trl                      | 0.12.2                                              |

EXAONE은 기존 파일럿과 한국어·모델 크기·학교 GPU 환경을 고려해 공통 모델로 선택했습니다. 현재 데이터에서 다른 모델보다 우수하다는 결론을 내린 것은 아닙니다. 공통 SFT 생략은 이번 비교의 실험 설계이며, SFT가 일반적으로 효과 없다는 뜻이 아닙니다.

프롬프트 버전은 `concise_by_qtype_no_system_v2`입니다. 모델 입력에는 아래 지시문 뒤에 `\n\n[질문]\n`과 질문 원문을 붙입니다. **참고 답변은 생성 입력에 넣지 않습니다.**

- 단답형: `다음 의료 질문에 한국어로 답하세요. 핵심 정답만 한 문장으로 작성하세요. 질문을 반복하거나 제목·목록·배경 설명을 덧붙이지 마세요.`
- 서술형: `다음 의료 질문에 한국어로 답하세요. 질문이 요구한 핵심 내용을 3~5문장 이내로 간결하게 작성하세요. 질문을 반복하거나 제목·목록·환자 정보 요약을 덧붙이지 마세요.`

## 공통 답변 생성

| 대상  | 질문당 답변 수 | 생성 조건                                     | 생성된 답변 수 |
| ----- | -------------: | --------------------------------------------- | -------------: |
| train |              5 | sampling, temperature=0.7, top_p=0.9, top_k=0 |         12,990 |
| valid |              1 | greedy (`do_sample=False`)                    |            288 |
| test  |              1 | greedy (`do_sample=False`)                    |            366 |

모든 생성의 `max_new_tokens`는 512입니다. 질문별·생성 번호별 seed는 공통 코드에서 고정합니다.

**train 질문은 2,598개이고, 생성 답변은 12,990개입니다.** 여러 번의 응답 결과를 통해 답변의 일관성을 살펴보고, 각 방법의 학습 재료로 활용합니다. 5번의 결과만으로 모델이 해당 지식을 확실히 안다거나 모른다고 단정하지 않습니다.

## 자동 채점과 검토

Claude API의 `claude-haiku-5-5`를 사용해 질문·참고 답변·모델 답변을 대조했습니다. 작은 실제·합성 표본으로 기본 동작을 확인한 뒤 전체 자동 채점을 수행했습니다.

| 라벨      | 의미                                                                     |
| --------- | ------------------------------------------------------------------------ |
| 정답      | 질문의 핵심을 충족하며 중대한 오류가 확인되지 않은 답변                  |
| 오답      | 답변을 시도했으나 핵심이 틀리거나 중요한 요구를 충족하지 못한 답변       |
| 거절      | 핵심 답을 하지 않고 명시적으로 모름·답변 불가를 표현한 답변              |
| 검토 필요 | 모호한 질문·참고 답변, 판정 모순, 생성 실패·기술 오류 등으로 보류한 항목 |

상담 권고 문구만 있다고 거절로 분류하지 않습니다. 정답 단어가 포함되어도 잘못된 치료 대안을 함께 제시하면 정답으로 자동 통과시키지 않습니다.

### train 결과

| 원래 자동 판정 | 답변 수 |
| -------------- | ------: |
| 정답           |   2,938 |
| 오답           |   8,901 |
| 거절           |       7 |
| 검토 필요      |   1,144 |
| 합계           |  12,990 |

잘린 답변 7개는 검토 대상으로 보존했습니다. 연결 오류·요청 거절 항목도 의학적 오답으로 처리하지 않았습니다.

표본 37개에 대한 AI 보조 검토에서 판정 수정 제안과 보류 사례를 확인했습니다. 이를 바탕으로 전체 결과에 추가 검토 표시를 붙여 **검토 후보는 총 1,202개**가 되었습니다. 기존 라벨은 수정하지 않았습니다. 따라서 위 표의 ‘검토 필요 1,144개’와 추가 검토 목록의 ‘1,202개’는 다른 집계입니다.

**이 결과는 잠정 자동 판정이며 의료 전문가 검증을 거치지 않았습니다.** 추가 검토 대상이 아닌 항목도 모두 검증됐다는 뜻은 아닙니다. 검토가 끝나지 않은 항목을 확정 정답·오답이나 거절 학습 목표로 사용하지 않습니다. 보류 항목을 제외할 경우 제외 수와 사용 질문 수를 함께 기록합니다.

## 원본 모델의 학습 전 성적

전체 질문 수를 분모로 계산한 **잠정 자동 평가 결과**입니다. 검토 항목을 오답에 합치거나 분모에서 숨기지 않았습니다.

| 지표      |  valid: 288개 |   test: 366개 |
| --------- | ------------: | ------------: |
| 정답      |  58개 (20.1%) |  75개 (20.5%) |
| 오답      | 207개 (71.9%) | 262개 (71.6%) |
| 거절      |      0개 (0%) |      0개 (0%) |
| 검토 필요 |   23개 (8.0%) |   29개 (7.9%) |

- test의 검토 항목에는 길이 제한으로 잘린 답변 1개가 포함됩니다.
- **오답률은 환각률과 같지 않습니다.** 별도의 근거 없는 주장 판정 없이 이름을 바꾸지 않습니다.
- 평가 표본·검토 항목 점검은 남아 있으며, 이 숫자는 최종 확정 성적이 아닙니다.
- 이후 설정 선택은 valid로 수행합니다. test 결과를 보고 학습 데이터·설정을 조정하지 않습니다.
